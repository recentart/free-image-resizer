How to resize an image

  1. Choose an image. Select a JPG, PNG or WebP file, or drag it onto the page.
  2. Set the dimensions. Enter a width or height in pixels, or pick 25%, 50%, 75% or 100%. Keep “Lock aspect ratio” on to avoid distortion.
  3. Resize. Pick the output format and quality, then click “Resize image”. You'll see the new dimensions and the real file size.
  4. Download. Click “Download Resized Image” to save the file to your device.

Questions

Is my image uploaded?

No. Your browser resizes the image with its built-in canvas feature. This site has no image-processing server, and the page's security policy blocks its scripts from sending data anywhere.

Is it free?

Yes. There's no sign-up, no watermark and no limit on how many images you resize.

Which formats are supported?

You can open JPG (JPEG), PNG and WebP images. Save the result in its original format, or convert it to JPG, PNG or WebP.

Will resizing make my file smaller?

Usually, if you make the image smaller, but not always. Converting to PNG, choosing a high quality setting or enlarging the image can make the file bigger. The tool shows the real size of the new file and how it compares with the original before you download.

What happens to transparent backgrounds?

PNG and WebP keep transparency. JPG can't store it, so transparent areas are filled with white. The tool warns you when this applies.

Is photo metadata kept?

No. The resized file doesn't include EXIF metadata such as camera details or GPS location. The photo's orientation is applied to the pixels, so it stays the right way up.

Is there a size limit?

Images can be up to 100 MB and 100 megapixels, and the result can be up to 16,384 pixels on each side. Phones and older computers can run out of memory with very large images. If that happens, try smaller dimensions.
